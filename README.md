# Calculator

## Overview
A browser-based calculator that performs basic arithmetic operations with proper state management and input validation.
This project exists to practice implementing application logic, handling edge cases, and structuring JavaScript beyond simple DOM scripts.

## Demo
- [Live URL](https://mukul-work.github.io/JS_calculator/)

## Features
- Supports addition, subtraction, multiplication, and division
- Handles chained operations without page reload
- Clear and reset functionality
- Prevents invalid inputs (e.g. multiple operators, divide by zero)

## Tech Stack
- JavaScript
- HTML
- CSS

## What I Learned
- Managing application state across user interactions
- Separating calculation logic from UI rendering
- Handling edge cases in user input and arithmetic operations
- Writing clearer, more maintainable JavaScript functions
